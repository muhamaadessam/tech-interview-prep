# Tech Interview Prep

منصة عربية مفتوحة المصدر للتجهيز لمقابلات البرمجة التقنية. يبدأ المشروع بمسار Flutter ومحتوى Dart أصلي مرتبط بالمراجع الرسمية.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

التحقق قبل النشر:

```bash
npm test
npm run typecheck
npm run build
```
